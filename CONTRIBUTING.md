# Contributing

Thanks for helping with FlipSend.

- Open an issue first for anything larger than a small fix.
- Keep changes small and focused. Add or update tests with each change.
- Android: `cd android && ./gradlew :core:test :app:testSideloadDebugUnitTest`.
- Windows: `dotnet test desktop`.
- Never commit signing keys, keystores, passwords, tokens, or `local.properties`.
- By contributing you agree your work is licensed under GPL-3.0-or-later.
